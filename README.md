# Sistema de Entregas con Drones Autónomos

Proyecto desarrollado en Java aplicando Programación Orientada a Objetos para simular un sistema de entregas con drones.

## Temas aplicados

- Herencia
- Encapsulamiento
- Métodos abstractos
- Polimorfismo
- Sobrescritura de métodos (@Override)
- Scanner
- Validaciones en setters
## Clases implementadas
### Clase abstracta /Padre
- Dron
### Clases hijas
- DronLiviano
- DronCarga
- DronEmergencia
### Clase principal
- MainDron
## Funcionalidades del sistema
- Ingreso de datos por teclado
- Validación de datos
- Cálculo del costo de entrega
- Uso de getters y setters
- Mostrar información del dron
- Recalcular costo al modificar valores
