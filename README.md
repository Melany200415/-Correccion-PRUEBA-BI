# Ejercicio 1 - Figuras 
El sistema fue diseñado utilizando una clase abstracta Figura para definir
atributos y comportamientos comunes a todas las figuras geométricas. Las
subclases Circulo, Rectangulo y TrianguloRectangulo implementan sus propias
fórmulas de área y perímetro aplicando herencia y @Override. En el método main
se utiliza un arreglo Figura[] para recorrer diferentes tipos de figuras y
llamar al método describir(), demostrando polimorfismo y manteniendo un código
limpio y reutilizable.
